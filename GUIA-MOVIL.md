# Guia de trabajo desde movil

## Enlaces

- Repositorio: https://github.com/Griker95/harfordweb
- Web publicada: https://griker95.github.io/harfordweb/

## Cambiar contenido desde GitHub

1. Abre el repositorio con la aplicacion de GitHub o el navegador del movil.
2. Entra en `Code` y abre el archivo que quieres modificar.
3. Pulsa el icono de edicion.
4. Guarda el cambio con un mensaje corto de commit.
5. GitHub Pages publica los cambios de `main` en unos instantes.

## Archivos importantes

| Que quieres cambiar | Archivo |
| --- | --- |
| Organizaciones | `js/organizations.js` |
| Personas de interes | `js/contacts.js` |
| Lugares de interes | `js/places.js` |
| Personajes de la compania | `js/characters.js` |
| Estilo visual | `css/styles.css` |
| Pagina de Inteligencia | `intelligence.html` y `js/intelligence.js` |

## Trabajar con Codex desde movil

1. Abre ChatGPT/Codex en el navegador del movil.
2. Inicia un chat de Codex en la nube y selecciona `Griker95/harfordweb` en la rama `main`.
3. Describe el cambio y menciona la pagina o el archivo si lo conoces.
4. Revisa el resultado y publica el cambio desde el propio chat cuando este listo.

Ejemplos de mensajes utiles:

- `Anade esta organizacion a js/organizations.js con estos datos: ...`
- `Corrige el formato de la ficha de Ograsado en movil.`
- `Revisa todas las fichas de Inteligencia y arregla las que se salgan de pantalla.`

## Si no hay cobertura

Guarda las ideas, textos o capturas en una nota del movil. Cuando vuelvas a tener conexion, pegalo en un chat de Codex o editalo desde GitHub. El sitio no necesita instalar dependencias ni ejecutar una compilacion.
